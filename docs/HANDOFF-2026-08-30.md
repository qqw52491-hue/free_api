## 二、本会话完成的能力（全部有单测/实测背书）

1. **可靠性修复**：子任务取消即时唤醒等待者 / 终态结果可消费 / 坏 JSON 行清理 / 孤儿子任务恢复 / 老库 result_json 迁移缺口
2. **持续监听 watch_start/watch_stop**：周期巡检文件或命令，变化事件走 durable inbox 自动注入；finish 门控拦截未释放的监听
3. **L2 只读侦察 worker（child_worker）**：独立上下文，读文件/列目录/只读命令白名单，10 步/180s/40k 观测硬顶，结构化回执
4. **L3 隔离写入 worker（child_writer）**：工作区复制成私有副本（跳过 .git），副本内改码+自跑测试，diff 回执，测试门禁拦截未验证交付；root 仍是真实工作区唯一写入者
5. **附件全文句柄**：上传附件自动登记为受管资源（.attachments/ 防覆盖），read_resource 支持非 UTF-8（解析引擎产出摘要）
6. **路由升级**：routing_mode（rules|scored 难度打分）+ role_models（角色→档位/钉死 UUID）+ 结构化失败信号（替代 ❌ 字符串匹配）+ 收官自动升维（is_endgame：总义务≥2、已完成≥2、剩 0-2 项 → 直接强模型）
7. **专精角色池（role_manager 工具 + UI 面板）**：角色卡=人设提示词+钉死模型+作用域+默认测试命令（DB 上限 8 张）；三个子任务派发点支持 "role" 参数挂载；AgentSettingsDrawer 有管理面板；tauri 命令 list/upsert/toggle/delete_role_card
8. **重复读取硬拦截**：四条件签名（同工具+同路径+内容哈希一致+第 3 次）→ 拒绝并给上次内容摘要；内容变化/压缩后自动放行；台账在 SandwichContext.read_ledger
9. **评测基础设施**：FREE_API_LIVE_MODEL_ID_PRO/FLASH/VISION 分槽、ROUTING_MODE、ROLE_MODELS、MAX_DURATION_MINUTES、REASONING_EFFORT 全部参数化；评分器否定词表修正（假阴性）；FREE_API_DB_PATH 隔离
