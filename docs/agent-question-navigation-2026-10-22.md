# 会话问题刻度

用户需要在长会话中按提问定位，并在悬停时看到很短的问题与回答摘录。

- 对已展示的用户新提问逐条生成刻度，旧聊天、历史回合和当前回合沿用各自的消息/回合锚点。
  相同文字的两次提问保留两个刻度；工具调用、专家心跳和人工确认不额外生成问题刻度。
- 预览问题最多 72 个 Unicode 字符，回答最多 96 个字符，分别显示至多两行；只取已有消息
  原文，去除部分 Markdown 外观后截取，不调用模型。没有回答时明确显示尚未回答或正在处理。
  回答存在性独立于文字摘录：纯代码/附件等被过滤后仍标为已回答，提示“已回答，暂无文字摘录”。
- 按展示顺序划分回答归属，新问题出现后不能用后来的回答填补旧问题的空白；预览不修改原文。
- 导航条置于滚动区外的侧边，不改变正文左边缘；当前阅读位置高亮。点击以原有 data-tl 身份
  在本组件内定位并短暂高亮，同时取消已排队的追尾滚动。跳转离开底部的平滑滚动初段即使仍在
  56px 阈值内也不能重开追尾；离开阈值后再回底部恢复正常跟随，“跟随最新”可立即主动恢复。
  新回合清除此跳转保护。新片段不会拉走历史阅读位置。
- 支持鼠标和键盘焦点预览、Enter/Space 跳转及 Escape 关闭预览；会话清空后移除旧刻度。
  标记很多时压缩间距并允许轨道内部滚动，不删除问题。

## 验证

`node scripts/test-agent-question-navigation.cjs` 验证真实投影与跳转函数：同文不同身份、未答问题
隔离、历史/当前回答、Unicode 截断、附件消息、100 次心跳不重复生成预览、空会话清理、局部
定位和取消追尾。另补回归：纯代码/附件/无摘录回答与真正未答区分；跳转平滑滚动最初仍靠近底部
时连续到达新输出不重开追尾；离开后回底恢复、显式恢复、重复跳转和无效锚点。既有成员进度、
实时预览、交付展示、审查进度/诊断与子任务关联回归同跑。

使用真实 AgentChatStream 的浏览器合成会话检查桌面与 390px 面板：刻度预览、点击跳转、当前
问题高亮、无横向溢出；运行中先跳回历史再追加合成思考片段，scrollTop 保持不变。未回答的新
问题正确显示等待说明。没有读取真实用户聊天做预览，也没有调用模型或自动续跑真实任务。

仅为前端导航；不新增后台接口、持久化表、审查要求或模型输入。摘要是原文开头的短摘录，
不是语义总结；正文很长时不保证摘录刚好覆盖核心结论。
