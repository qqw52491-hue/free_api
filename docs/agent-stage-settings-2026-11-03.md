# 固定环节配置

本轮先抽取固定位置的开关，未新增流程编排引擎。随后桌面正式 reviewer 执行器迁移见 [正式审查接入通用 Agent](agent-review-main-executor-2026-11-03.md)。

## 配置与页面

主任务在模型配置的审查页设置 `stages`；角色默认组合及派发参数使用 `execution.stages`。两处共用页面组件与后端 `StageSettings` 类型。

| 字段 | 开启 | 关闭 |
|---|---|---|
| plan | 写入及交付前须保存正式方案 | 不因自动分流强制正式方案，允许自主思考 |
| plan_review | 正式提交方案时派发审查，不走自动快放行 | 保存方案而不自动派审，回执不冒充审查通过 |
| stage_review | 按已有写入/阶段推进条件触发，不受 auto 模式或旧关闭覆盖影响 | 不新增中途审查 |
| final_review | 启用适用材料的终审，可覆盖交接任务默认免独立终审和分流 mechanical_only | 不新增独立终审，验证仍执行 |

省略或 null 为自动/沿用任务默认。主任务默认沿用原策略；handoff 子任务在 auto 模式下默认关闭四个重复环节，不再继承父任务的方案模式。完整 delivery 子任务默认沿用原策略；显式 cross_review/plan_approval 保留相应模式，可用上述字段进一步设置，人工审批不能与关闭方案同时配置。

关闭方案时页面同时关闭方案审查；开启方案审查时同时开启正式方案。后端拒绝相反的显式组合。关闭固定环节不禁用用户主动要求的调查、验证或显式工具调用，也不撤销已有有效审查阻塞、目录权限、输入输出契约或人工批准。

最终审查“开启”表示启用原有终审，仍遵循材料适用条件；没有文件或写入的纯文字答复可以沿用原免审策略，不要求每条回答都调用审查模型。

## 恢复与兼容

有效开关进入原 AgentCheckpoint，影响方案状态投影和交付收据指纹。续跑沿用原任务配置；页面修改用于新任务，旧检查点缺失字段时保持原策略。续跑时用户显式切换人工方案批准可加严方案要求。各环节优先读取固定配置，模型分流与方案声明不能把显式关闭重新打开。

显式隔离仍保留原适配；桌面正式 reviewer 随后的迁移使用关闭内部重复环节的通用主循环，审查结果仍交原流程处理。无宿主调用保留兼容适配，详细边界见上述记录。

人工批准通过原 ask_human 审批通道持久化；未显式开启 Agent 方案审查时，不必再走 submit_plan。显式要求正式方案时，写入与交付共同接受有效的人工批准留痕；自动 Approved 标记不等于已经批准的人工方案，拒绝或重新打开审批后也不能借旧留痕放行。

阶段审查显示按执行端优先级处理：明确的 stages.stage_review 覆盖旧 stage_reviewer_override，未明确时沿用旧值。旧“关闭阶段审查”按钮同步写入新开关 false；选择“智能风控/严格把关”恢复阶段自动策略，不清除其他固定环节。页面徽标只说明阶段审查关闭，不再笼统显示“免审”。

## 人工批准与 Agent 方案审查组合

人工审批模式只有在显式 stages.plan_review=true 时接通 submit_plan 原派发入口；模式仍为 plan_approval，不会因派审切换成自动放行。随后用原 wait_jobs 收齐并消费同批审查，再通过原 ask_human 呈报。只开人工审批或方案审查为自动/关闭时，原直接呈报入口保留。

审批卡正文使用已保存的当前方案、本批当前有效裁决/发现及成功失败回执数；按钮与自由文本批准的来源记录对应所呈报材料。完成审查不等于批准：包括全员同意的情况，都须等人工明确批准后实施和交付。审查打回或技术失败不剥夺人工仲裁，实际意见与失败一并披露。审查尚在途时按原批次等待，不重新派发；显式非审批类求助不被这个组合等待拦住。

新方案修订仍由原 commit_plan_submission 清除旧人工批准，续跑复用原批次与检查点，不新增工作流、状态字段或审批轮次。核心说明、固定环节提示和页面组合说明同步选型。

新增两项回归覆盖组合默认/关闭/开启、原提交入口适用性、两人批次等待、全员同意与打回/技术失败的两种回收、审批材料、写入与正式交付、人工批准/拒绝、检查点恢复和修订失效。完整 Rust 1453 通过、116 项失败均为本机 HTTP bind PermissionDenied、10 项原有忽略、跳过真实剪贴板；审批材料使用有效裁决投影后组合回归复跑通过。cargo check --tests、后端 build、前端类型检查/build、git diff --check 通过。未真实模型或桌面交互实测，未重启应用、未修改真实会话。
