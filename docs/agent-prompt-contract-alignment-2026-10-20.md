# Agent 提示词与执行契约对齐（2026-10-20）

## 问题与范围

用户提供的运行自评报告了四类问题：并行查询被额度拒绝、只读查询形成验证负担、引用步骤边界说明不清、凭旧知识否定当前模型版本。本轮对照当前源码修复可复现的契约不一致，不将自评中的因果解释视为已经证明的事实。

## 修改

- `model_manager.list_specs/list_platforms`（包括缺省 list_specs）按已实现动作识别为只读，可与其他已识别只读工具组成最多四路的批次；未知或写动作仍采用两路上限。JSON 与树节点均按执行端实际参数优先级识别，顶层写动作和 args 中的写动作不能被旁边的查询字段掩盖。
- 台账复用模型查询动作定义，模型管理写动作不再被整个工具的只读白名单漏掉。shell 台账接受执行端支持的字符串简写及 script/command_line/CommandLine/input 字段，完整脚本优先级与执行端保持一致；写重定向及 POST 继续入账。
- 核心提示词与历史规则卡统一使用 step_N 举证，说明严格晚于最近副作用且已执行完成。过期引用错误显式解释同一步不满足要求。output_id 可补充关联，不能在现有新鲜度校验中单独证明时序。
- 五阶段按任务适用性推进，允许新证据触发重新调查；只读任务没有挂账副作用时无需写入验证或免测申报。查询被保守入账时，可以核实实际命令后说明无变更的具体理由，避免运行无关验证。
- 补充时效性事实核验指导，禁止仅凭记忆中没有就否定版本存在；接口声明的模型名与底层身份区分。未新增搜索次数、milestone 证据或知识核验的宿主阻断门。

## 长度与成本

第一批修改保留原有主体，未做大幅压缩。核心文件修改前 27,540 字符、第一批修改后 28,032 字符。仓库估算器（含安全冗余）估计约从 17,035 增至 17,431 tokens；这不是供应商 tokenizer 实测，也不是每轮完整输入总量。应连同工具目录、工作区规则、动态状态与历史一起评估成本。

OpenAI 的公开资料说明 Codex 使用包含指令、工具定义等内容的稳定前缀来改善缓存复用；公开 starter prompt 不等于任何版本桌面产品的完整请求。没有公平样本可断言当前完整提示词比 Codex 长或短。缓存命中可能降低重复输入成本和延迟，但本轮没有调用付费模型测量真实命中、正确率或总 token 收益。

## 验证与边界

新增三项回归覆盖并行混合批次/两种树形入口/参数优先级、查询参数形态与真实写操作区分、步骤边界拒绝后重试及提示词举证范例经真实校验。临时数据目录完整 Rust 测试 1,204 通过，10 项既有忽略，跳过 Wayland 剪贴板实机测试。

未复盘自评中六条命令的完整运行轨迹，不宣称字符串简写就是那次误入账的原因。本轮未新增通用 SQL 静态判定，不把含 SELECT 或缺少常见写命令视为无副作用保证；SQLite 查询仍可能被保守入账，应具体说明实际操作或使用已知只读查询工具。没有实测证明时效性指导会消除模型误判，也没有付费模型行为对照。

## 第二批：规格内部一致性

用户批准逐条核实后的确定修改，保留未证实的问题和产品设计取舍：

- 去除固定数量和显式输出竞争假设的要求；保留必要的依据说明，复用 thought/finding 的现有约定。
- 统一读取基线：修改已有文件须了解待改内容，整文件重写须了解完整原文；已读且有效的内容可复用，新建文件先确认是否存在。删除 write_file 的“免先读”例外，没有修改读取或写入门禁。
- 常规入口补为 tool/parallel/plan_tree/commands 四种，另行说明专用入口；commands 顺序执行、失败停止、不回滚此前成功步骤，不支持计划树结果引用。
- 补计划树的数组串行结构、对象字段/数组下标引用和未解析引用边界。真实执行旧示例复现 seq 包装被当作 core 工具；新示例用实际支持的数组，并通过真实 task_store 创建、结果引用和读取验证，不扩展解释器协议。
- tool 前置改为展示建议，使用字段顺序不同的原始 JSON 经过解析、归一化及真实 local_shell 分发验证行为；不引入键序门禁。
- 插件级目录改为先能力检索/加载 schema，再准确调用完整工具名；同步修改尾部说明。操作根目录与项目绑定分别说明，不改变文件权限或路径映射。
- 当前日期与宿主 UTC 偏移投影到请求尾部，每次组装读取宿主日期；不写入静态系统前缀，不注入秒数。测试覆盖跨日、同日秒数稳定和相同瞬间不同时区的日期差异。日期不证明模型发布或服务身份。
- §7 与最终交付示例残留的文字摘要/output_id 单独举证统一为 step_N，全部 verified 示例经真实时序校验。允许相关只读状态观察作为证据，避免与状态探针说明互斥；已有查询误入账时的免测申报不再与“仅真实写入后申报”冲突。
- 改“状态与记忆通道”标题，说明记忆满额拒绝新增、同 key 更新，不新增自动淘汰策略。串联 shell 示例改用声明的 local_shell 并保留原验证退出码。

第二批后核心文件 29,017 字符，仓库保守估算约 18,082 tokens；新增文字用于说明执行边界，本轮不以缩短字数为目标。没有新增 notes、partial、milestone 证据门禁，没有改写用户角色卡、删除验证披露或变更 human 闭合策略。

隔离临时数据目录完整 Rust 回归 1,207 通过，10 项既有忽略，跳过 Wayland 剪贴板实机测试，cargo check 通过。新增三项测试及既有测试扩展覆盖日期投影、键序分发、文档计划树实执行、作用域措辞及举证范例。未付费验证真实模型是否减少误解或额外调用。
